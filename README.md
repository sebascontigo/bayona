# BAYONA — Where Science Meets Movement

No es fitness. Es transformación.

## Deploy

This site is ready for Vercel deployment:

1. Push to GitHub
2. Import project in Vercel
3. Deploy automatically

Build command: `npm run build`
Output directory: `dist`

## Development

```bash
npm install
npm run dev
```

## Stack

- React 18 + Vite
- Three.js / React Three Fiber
- Framer Motion
- Lenis smooth scroll
